# จดไว — เดโมบัญชีสำหรับทำต่อในคอม

## UI6 Afterglow — demo.28

รุ่นนี้รวมกราฟแบบ PowerPoint Morph, จดบ่อยก่อนรายการล่าสุด, กรอบแยกรายการในภาพรวม/ประวัติ/รายวันจากปฏิทิน และกรอบถังขยะบัญชีที่สมบูรณ์ คงข้อมูล `jot-money-v1` และกลไกบัญชี/งบเดิม ผู้ใช้อนุมัติให้อัปเดตเว็บแล้ว; บันทึก local รุ่นก่อนด้านล่างเป็นประวัติ

รุ่นนี้รวม UI6 และการแก้หน้ารายการ/ปฏิทินครบ 5 ประเด็น เว็บเดโม: https://jot-money-demo.pages.dev/ ข้อมูลในเบราว์เซอร์เดิมยังอยู่ ไม่เปลี่ยน localStorage key และไม่ใส่ข้อมูลตัวอย่างให้ผู้ใช้ใหม่

เก็บ 5 ข้อจากการตรวจหน้าประวัติ: พื้นที่สรุปมือถือกระชับขึ้น มีคำอธิบายยอดสุทธิที่เห็นทันที ปุ่มล้างคำค้นใหญ่ขึ้น วันที่ว่างดูเรียบขึ้น และปิดแก้ไขแล้วกลับไปยังรายการเดิม (ถ้าย้ายวัน/ลบจะไปยังรายการที่เหลือหรือจดเพิ่ม) ลองเมนูรายการ ค้นหา และแตะวันในปฏิทินได้ตามเดิม

ปรับหน้ารายการและปฏิทินเพิ่มเติมให้โปร่งและอ่านง่ายขึ้น: ลดกรอบซ้อน จัดหัววันกับยอดสรุปใหม่ และทำสถานะวันที่ชัดขึ้น ลองผ่านเมนู **รายการ** แล้วสลับ **รายการทั้งหมด / ปฏิทิน**; แตะหัววันเพื่อจดย้อนหลัง หรือแตะวันที่ในปฏิทินเพื่อดู/แก้ไขรายการและจดเพิ่มได้เหมือนเดิม

รอบเก็บรายละเอียด Impeccable: บัญชีที่เลือกเองไม่ถูกระบบเดาทับ, แจ้งรูปแบบการพิมพ์ยอดเดียวชัดขึ้น, รองรับลิงก์ข้ามเนื้อหา/H1, ขยายตัวอักษรและพื้นที่แตะปฏิทินมือถือ และย่อกราฟข้อมูลวันเดียวพร้อมปุ่มดูเดือน ยังคงข้อมูลเดิมและทำเฉพาะ local

ผู้ใช้เลือก **Afterglow — กระจกยามค่ำ** แล้ว: โทนกรมท่า กระจกควัน มินต์และลาเวนเดอร์ ใช้ระบบเดียวทั้งแอป ภาพรวมเปลี่ยนเป็นยอดและกราฟแบบไม่ครอบการ์ด รายการล่าสุดต่อเนื่องด้านล่าง มือถือรวมเมนูสี่หน้ากับปุ่มจดปุ่มเดียวใน dock โปร่งแสง พร้อมการเคลื่อนไหวและ reduced motion/opaque fallback

ลองในเครื่องที่ http://127.0.0.1:8000/ แล้วรีเฟรช กราฟเริ่มที่สัปดาห์นี้; ยอดปัจจุบันไม่เปลี่ยนตามช่วงกราฟ คงข้อมูล `jot-money-v1` และทุกฟีเจอร์เดิม รวมการเลือกบัญชีที่เลื่อนได้เมื่อพื้นที่จอสั้น ผู้ใช้อนุมัติเผยแพร่ demo.27 แล้ว บันทึก local/รุ่นเก่าด้านล่างเป็นประวัติก่อนออกรุ่นนี้

ตรวจด้วย `node ui6-browser-check.cjs --no-shots` (Chrome แยกโปรไฟล์/ข้อมูลสังเคราะห์); `--review` เก็บเฉพาะภาพสำหรับตรวจดีไซน์ ครอบคลุม 320/375/430/1280 และพื้นที่คีย์บอร์ดจำลอง ไม่ใช่การทดสอบ Safari/iPhone จริง

หน้าเลือกตัวอย่างเดิมเป็นเครื่องมือแยกที่ http://127.0.0.1:8016/ ไม่ใช่เว็บแอป เปิดด้วย `start-design-picker.cmd` หากต้องการกลับไปดูแนวทาง ชุด Safer/Bolder เป็นตัวอย่างที่เตรียมไว้ ไม่สร้างใหม่ด้วย AI

## UI5 Glass Ledger — demo.26 (รุ่นเผยแพร่ก่อนหน้า)

ใช้สไตล์การ์ดกราฟที่ผู้ใช้เลือกเป็นระบบเดียวทั้งแอป เพิ่มผิวกระจกโปร่งแสงโทนม่วงดำ–มินต์ พร้อมพื้นทึบสำรองเมื่อไม่รองรับ/ลดความโปร่งใส หน้าภาพรวมไม่มีฟอร์มวางค้างแล้ว: กดปุ่ม **จดรายการ** เพื่อเปิดแผงและพิมพ์ทันที ยังเลือกวันที่ บัญชี หมวด และโอนได้ครบ ปิดแล้วร่างยังอยู่ วันจากปฏิทินยังจดย้อนหลังได้

กราฟ รายการประจำ และจดบ่อยยังอยู่ ยอดปัจจุบันไม่เปลี่ยนตามช่วงกราฟ เก็บข้อมูล `jot-money-v1` เดิม ไม่ล้างบัญชี/รายการ/งบ ไม่มีข้อมูลสาธิตสำหรับผู้ใช้ใหม่ สำรอง UI4 ก่อนเปลี่ยนไว้ที่ `ui-versions/ui4-before-ui5-2026-10-12/dist/` ในเครื่อง

ตรวจ Chrome synthetic 320/375/430/1280 รวม 320×568, จำนวนเงินยาว, แก้/บันทึก/ยกเลิก/ย้อนวัน และ storage failure ผ่าน ไม่ใช่การทดสอบ Safari/iPhone จริง คะแนน impeccable 30/40 หลังแก้ 3 ปัญหาที่ผู้ตรวจพบ (29/40 รอบแรก; คะแนนปรับเฉพาะจุด ไม่ใช่ประเมินใหม่เต็มชุด) รายงานอยู่ใน `.impeccable/critique/`

คำสั่งตรวจ: `node ui5-browser-check.cjs`, `node import-check.cjs --synthetic`, `node import-ui-check.cjs --synthetic`; ใช้ `--no-shots` เพื่อไม่บันทึกภาพ ตรวจไฟล์เผยแพร่ด้วย `node deployment-ui5-check.cjs https://jot-money-demo.pages.dev/` ข้อความ local/UI4 ด้านล่างเป็นประวัติก่อนรุ่นนี้

การจดล่าสุด: ถ้ามีหลายบัญชี พิมพ์แล้วกด **ถัดไป · เลือกบัญชี** หรือ Enter จะเปิดหน้าต่างบัญชีพร้อมสรุปยอด/วันที่ เลือกบัญชีแล้วกดยืนยันบันทึก แอปเสนอจากบัญชีที่ใช้กับชื่อรายการและประเภทนั้นซ้ำอย่างน้อย 2 ครั้ง เปลี่ยนได้เสมอ ถ้ามีบัญชีเดียวกดบันทึกได้ทันที ปิดหน้าต่างแล้วร่างยังอยู่ กรณีบันทึกไม่สำเร็จจะเก็บร่างไว้ให้ลองใหม่

ปรับ local ล่าสุดตามภาพอ้างอิง: เงินรวมปัจจุบันและกราฟอยู่ในการ์ดเดียว พื้นม่วงดำไล่เขียวเข้ม เส้นมินต์และพื้นที่สีจางใต้เส้น แตะกราฟเพื่ออ่านยอดเต็มในป้ายลอย เลือกสัปดาห์/เดือน/ปีได้ (เปิดที่เดือนปัจจุบัน) ยอดใหญ่ยังเป็นยอดปัจจุบันไม่เปลี่ยนตามช่วงกราฟ ปุ่ม “จดเลย” เข้าช่องพิมพ์และรักษาร่าง/วันที่ กฎคำนวณและข้อมูลเดิมไม่เปลี่ยน

งาน local ล่าสุด: **UI4 และกราฟเงินรวม** — ลองที่ http://127.0.0.1:8000/ แล้วรีเฟรชหน้า มือถือเรียงการ์ดยอดเงินพร้อมกราฟก่อนช่องจด เดสก์ท็อปกราฟซ้าย/จดขวา ปุ่มจดเลยช่วยข้ามกราฟไปพิมพ์ทันทีโดยไม่เสียร่าง ไม่ได้เผยแพร่เว็บ

กราฟแสดงย้อนหลังได้ทันทีถึงวันแรกที่มีรายการ โดยคำนวณจากยอดปัจจุบันย้อนรายการกลับ ไม่ต้องกดเริ่มติดตาม ยอดย้อนหลังขึ้นกับความครบของประวัติ และสมมติว่ายอดตั้งต้นของบัญชีปัจจุบันมีอยู่ตลอดช่วง หากเพิ่มบัญชีทีหลังหรือจดไม่ครบ ยอดเก่าอาจคลาดเคลื่อน มีคำอธิบายในกราฟ ยอดนี้ไม่รวมบัญชีหนี้และรายการอนาคต ไม่เปลี่ยนยอดบัญชีหรือประวัติเดิม

**จดบ่อย** เรียนรู้จากชื่อรายการและประเภทเดียวกันอย่างน้อย 3 ครั้งใน 2 วันขึ้นไป เสนอสูงสุด 4 รายการ เรียงความถี่/วันที่ล่าสุด เลือกบัญชี หมวด และยอดที่ใช้บ่อย กรณีเท่ากันเลือกเวลาล่าสุดแล้วลำดับบันทึก แตะเพื่อตรวจแก้ยอด/บัญชี/หมวดก่อนกดบันทึกวันนี้ มีแก้ไขหรือยกเลิกรายการล่าสุด ซ่อนคำแนะนำได้ และคืนทั้งหมดที่ตั้งค่า รายการประจำที่ตั้งเองยังอยู่แยกกัน ไม่มีการบันทึกโดยอัตโนมัติ

ยังไม่เผยแพร่ UI4 และคง VERSION demo.25 ซึ่งเป็นรุ่นที่อยู่บนเว็บ สำรอง UI3 ก่อนแก้ไว้ที่ `ui-versions/ui3-before-ui4-2026-10-12/dist/`

งาน local เพิ่มเติม: **รายการประจำแตะเดียว** — ที่ภาพรวมกด “เพิ่มรายการประจำ” ตั้งชื่อ ยอด ประเภท หมวดและบัญชี จากนั้นแตะรายการที่ภาพรวมเพื่อบันทึกวันที่วันนี้ มีแก้ไขและยกเลิกรายการล่าสุด จัดการชุดรายการได้ในตั้งค่า ยังเป็นฟีเจอร์ในเว็บแอป ไม่ใช่ Widget ของ iPhone

งาน local ล่าสุด (ยังไม่เผยแพร่): เพิ่มแท็บ **ตั้งค่า** ถัดจากบัญชี เพื่อจัดการหมวดรายรับ/รายจ่าย นำเข้า Excel ส่งออก CSV คืนข้อมูลก่อนนำเข้า และเริ่มใหม่ ใช้ข้อมูลเดิมทั้งหมด ทดลองที่ http://127.0.0.1:8000/; VERSION ยังเป็นรุ่นเผยแพร่ demo.25

รุ่น 0.1.0-demo.25 วันที่ 11 ตุลาคม 2026: ช่องจดอยู่ก่อนสรุปยอดบนมือถือ เพิ่มบัญชีแรกจากช่องจดได้โดยตรงและกลับมาพิมพ์ต่อ ปรับความชัดข้อความ/ปุ่ม เพิ่มชื่อปุ่มค้นหา และมีทางลัดไปส่งออก CSV ใต้ภาพรวม CSV เก็บรายการไว้อ่านได้ แต่ยังใช้กู้คืน state ของแอปไม่ได้ ผู้ใช้อนุมัติอัปเดตเว็บเดโมแล้ว

## UI3 Midnight Journal — รุ่นเดโมปัจจุบัน

UI3 Midnight Journal ใช้โทนกรมท่า–ไอวอรี–เขียวและทองหม่นจากหน้าต่างรายวันเป็นระบบเดียวทั้งแอป: ภาพรวม จดรายการ ประวัติ ปฏิทิน สรุป บัญชี งบ โอน และหน้าต่างจัดการทั้งหมด พร้อม fade เปลี่ยนหน้า/เปิดส่วนย่อย แสงตอบสนองการแตะ และข้อความบันทึกสำเร็จเคลื่อนไหว รองรับ reduced motion

เปิด https://jot-money-demo.pages.dev/ หรือ http://127.0.0.1:8000/ ข้อมูลยังใช้ `jot-money-v1` เดิม ไม่มี schema ใหม่หรือข้อมูลสาธิต สำรอง UI2 ทั้งแอปไว้ที่ `ui-versions/ui2-2026-10-09/dist/` พร้อม SHA256.json; UI1 เดิมยังอยู่ UI3 ใช้ ui2.css เป็นฐาน layout แล้วเพิ่ม ui3.css/ui3.js ไม่ใช่ตัวสลับธีม เผยแพร่เป็นรุ่น 0.1.0-demo.24 เมื่อ 9 ตุลาคม 2026

ข้อความ UI2 เป็นหน้าตาหลักด้านล่างเป็นประวัติรุ่นที่เผยแพร่ก่อน UI3

เพิ่มแท็บ “รายรับตามหมวด” ในกราฟวิเคราะห์ ข้างรายจ่ายและรายสัปดาห์ ใช้ Interactive Donut โทนเขียวพร้อมยอด/เปอร์เซ็นต์เฉพาะรายรับของเดือนเดียวกัน ไม่รวมโอนและปรับยอด มีสถานะไม่มีรายรับ

ปรับกราฟวิเคราะห์เป็นแท็บแยก “รายจ่ายตามหมวด / รับ–จ่ายรายสัปดาห์” โทนกรมท่า/เขียว/แดงสุภาพ Donut มีรอยแบ่งและแถบสัดส่วนหมวด กราฟแท่งมีช่วงวันที่ และการ์ดยอดรับ–จ่าย–สุทธิของสัปดาห์ที่เลือก เริ่มจากสัปดาห์ที่ยอดรับ+จ่ายมากที่สุด ตัวเลขยาวจัดแถวบนมือถือ คงสูตรเดือนและข้อมูลเดิม

เพิ่ม “ดูกราฟวิเคราะห์” ใน รายการทั้งหมด → สรุป เปิด dialog แยกรายจ่ายตามหมวดด้วย Donut และเทียบรับ–จ่ายรายสัปดาห์ด้วย SVG ไม่เพิ่ม dependency ใช้เดือนที่เลือกและข้อมูลทั้งหมด ไม่ใช้คำค้น ไม่รวมโอน/ปรับยอด แตะหมวดหรือสัปดาห์เพื่อดูยอดเต็ม มีตารางตัวเลขและสถานะว่าง ข้อมูลเดิมไม่เปลี่ยน

ชุดตรวจเพิ่ม: `node analytics-check.cjs`, `node chart-view-check.cjs`, `node history-ui-check.cjs`

หน้ารายการทั้งหมดมีตัวเลือก “รายการทั้งหมด | ปฏิทิน | สรุป” ค้นหาเปิดเป็นหน้าต่างทับหน้า แท็บ “สรุป” แสดงรายสัปดาห์ในเดือนแทนไตรมาส เลือกปีและเดือนเพื่อดูทุกช่วงจันทร์–อาทิตย์ นับเฉพาะวันที่ในเดือน ยอดทุกสัปดาห์รวมตรงกับยอดเดือน นำเข้า/ส่งออก/คืนข้อมูลอยู่ใน “จัดการข้อมูล” ของแท็บนี้ ใช้ข้อมูลทั้งหมดไม่จำกัดเดือน และคำค้นหน้ารายการไม่กรองยอดสรุป

รุ่น demo.23: แตะวันในปฏิทินเพื่อเปิดหน้าต่างยอดสรุปและรายการของวันนั้น กดรายการเพื่อแก้ไข/ลบ หรือจดเพิ่มตามวันที่เลือก ไม่มีรายละเอียดรายวันซ้ำใต้ปฏิทิน คงสรุปเดือนตามเดิม ผู้ใช้อนุมัติเผยแพร่รุ่นนี้วันที่ 8 ตุลาคม 2026

แก้ช่องวันที่โอนที่กว้างเกินช่องอื่นบน iPhone/Safari ให้มีขนาดเท่าช่องอื่นและจัดวันที่ชิดซ้าย คงตัวเลือกวันที่และการบันทึกเดิม ตรวจ Chrome ขนาด 320/375/390/430/1280 ผ่านแล้ว ยังต้องยืนยันบน iPhone 13 จริง

## UI2 — หน้าตารุ่นก่อนหน้า

UI2 Quiet Atelier เป็นรุ่นก่อนหน้า สำรองทั้งแอปไว้ใน `ui-versions/ui2-2026-10-09/dist/` ไม่มีปุ่มเปรียบเทียบหรือระบบสลับธีมในแอป ข้อมูลและฟีเจอร์เดิมยังอยู่

เก็บต้นฉบับ UI1 ก่อน redesign ครบไว้ใน `ui-versions/ui1/dist/` พร้อมเอกสารและชุดตรวจ ณ ตอนนั้น และสำเนา `dist/ui1/` สำหรับกู้คืนในอนาคต ไม่ใช้เป็นตัวเลือกในแอป ไม่ควรจดข้อมูลพร้อมกันหลายแท็บ เพราะแอปยังไม่มีการซิงก์ข้ามแท็บ

UI2 ใช้ `dist/ui2.css` และส่วนหัว HTML ใช้ Noto Sans Thai ที่เก็บใน `dist/vendor/fonts/` พร้อม OFL โดยไม่โหลดฟอนต์จากภายนอกขณะใช้แอป ไม่เพิ่ม backend หรือ framework การเอาตัวเปรียบเทียบออกไม่เปลี่ยนกฎข้อมูลและการบันทึก

ทิศทาง UI2 ล่าสุดเป็น Quiet Atelier: ไอวอรีอุ่น กราไฟต์ และกรมท่าเข้ม ลดสีน้ำเงินสด เงาฟุ้ง และความหนาของตัวอักษร ใช้ชุดสีและองค์ประกอบร่วมกันทุกหน้า โดยยังแยกรายรับสีเขียวและรายจ่ายสีแดงสุภาพ พร้อมเครื่องหมายตัวเลขตามเดิม UI1 ที่เก็บไว้ไม่เปลี่ยน

## เปิดมาแล้วจด

ผู้ใช้ใหม่ใน local เริ่มด้วยหมวดรายจ่าย 9 หมวด: อาหารและเครื่องดื่ม, เดินทางและรถ, บ้านและบิล, ซื้อของและของใช้, สุขภาพ, การศึกษา, บันเทิงและท่องเที่ยว, ครอบครัวและสัตว์เลี้ยง, รายจ่ายอื่น ๆ และรายรับ 6 หมวด: เงินเดือน, รายได้เสริม, ขายของ, ผลตอบแทนและดอกเบี้ย, ของขวัญและเงินช่วยเหลือ, รายรับอื่น ๆ พร้อม “รอจัดหมวด” ทั้งสองประเภท เพิ่ม/แก้ชื่อและจำหมวดได้ตามเดิม ผู้ใช้ที่มีข้อมูลบันทึกไว้เดิม (รวมบัญชี/รายการว่าง) คงหมวดเดิม ไม่แทรกชุดใหม่ และไม่เปลี่ยนประวัติหรือยอด
หากต้องการดูชุดใหม่ ให้ใช้เบราว์เซอร์หรือ profile ทดสอบที่ไม่มีข้อมูลเดิม อย่าล้างข้อมูลจริงเพื่อทดลอง การกดเริ่มใหม่เป็นการล้างข้อมูลโดยเจตนาและจะได้ชุดหมวดใหม่

ปรับใน local วันที่ 8 ตุลาคม 2026: วันที่อยู่แนวเดียวกับหัวข้อ “จดรายการ” แบบข้อความและไอคอนเรียบ ไม่มีกรอบเด่น แสดงป้ายเฉพาะย้อนหลัง/ล่วงหน้า จอแคบวางใต้หัวข้อ แตะเพื่อเลือกวันหรือใช้ Tab เพื่อแก้ด้วยคีย์บอร์ด งานนี้ยังไม่เผยแพร่ เว็บยังเป็น demo.18 เดิม

หน้าแรกมีสรุปเงินกระชับ แล้วตามด้วยช่องจดทันที บัญชีทั้งหมดดูผ่านปุ่มในสรุป หรือหน้า “บัญชีและงบ”
กดปุ่มบัญชีในฟอร์มเพื่อค้นหาชื่อหรือกลุ่มบัญชี เฉพาะบัญชีของตัวเองที่ยังใช้งานได้ ไม่แสดงผู้ยืม/บัญชีซ่อน/บัญชีลบ
จำบัญชีที่เลือกหรือใช้จดล่าสุดใน `jot-money-v1-last-account` (ตั้งค่าแยก ไม่เปลี่ยน ledger `jot-money-v1`); ถ้าบัญชีนั้นใช้ไม่ได้จะเลือกบัญชีใช้งานได้บัญชีแรก
การเลือกบัญชีไม่ล้างข้อความหรือหมวดที่เลือก และใช้ได้จากแผงจดลอยด้วย

ระบบจำหมวดใน local: เลือกหมวดเองแล้วบันทึก หรือแก้หมวดรายการเดิมแล้วบันทึก ระบบจำชื่อรายการเดียวกัน (ไม่สนตัวพิมพ์/ช่องว่างซ้ำ) แยกรายรับกับรายจ่าย ใช้หมวดที่เลือกบ่อยที่สุด หากเท่ากันใช้การเลือกที่ยืนยันล่าสุด พร้อมข้อความ “จำจากหมวดที่คุณเลือกบ่อย” และยังเปลี่ยนเองได้ เริ่มเก็บหลักฐานตั้งแต่ฟีเจอร์นี้ ไม่เดาว่าหมวดเก่าหรือนำเข้าเป็นสิ่งที่ผู้ใช้เลือกเอง หมวดที่ระบบเลือกให้อัตโนมัติไม่นับคะแนนเพิ่ม หากยังไม่มีหลักฐานใช้กฎคำเดิมหรือรอจัดหมวด ไม่เปลี่ยนหมวดในรายการเก่าเอง ไม่ส่งข้อมูลออกจากเครื่อง
ช่อง “วันที่รายการ” เริ่มเป็นวันนี้ตามเวลาไทยเมื่อเปิดแอป/แผงจด และกลับเป็นวันนี้หลังบันทึก เลือกวันย้อนหลังหรือวันอื่นได้ ทั้งรายรับ รายจ่าย และวันที่โอน โดยบันทึกวันที่ที่เลือกลงประวัติและปฏิทิน

## รุ่น 0.1.0-demo.18: รายการรายวันและปฏิทิน

เปิดหน้า “รายการทั้งหมด” จะเห็นรายการแบ่งตามวัน กด “ปฏิทิน” เพื่อดูเดือนปัจจุบัน
ใน local มีปุ่ม “จดวันที่นี้” ที่หัวกลุ่มวัน และใต้ปฏิทินหลังเลือกวัน (แม้ยังไม่มีรายการ) เพื่อเปิดแผงจดเดิมพร้อมวันที่นั้น รองรับรายรับ/รายจ่าย/โอน หลังบันทึกยังอยู่หน้าประวัติและวันนั้น หากแก้วันที่จะตามไปวัน/เดือนใหม่ในปฏิทิน ปุ่มจดทั่วไปยังเริ่มวันนี้ คำค้นเดิมยังมีผลและแสดงข้อความแจ้งผลกรอง
ใช้ปุ่มเดือนก่อนหน้า/ถัดไปดูประวัติ และกดวันที่เพื่อดูยอดเต็มและรายการ แตะรายการเพื่อแก้ไขวันที่ จำนวนเงิน หรือลบตามเดิม
ช่องค้นหาใช้ร่วมกันทั้งสองมุมมอง เมื่อค้นหา ยอดทุกส่วนมาจากรายการที่ค้นพบ พร้อมข้อความแจ้งชัดเจน

สุทธิ = รายรับ − รายจ่าย ไม่ใช่เงินคงเหลือบัญชี รายการโอนและปรับยอดหนี้ไม่รวมในสูตร แต่ยังอยู่ในประวัติ
ตัวเลขในช่องวันอาจย่อ K = พัน, M = ล้าน, B = พันล้าน; เลือกวันเพื่อดูยอดเต็ม
บนมือถือ ช่องวันแสดงสุทธิ: + สีเขียว = รับมากกว่าจ่าย, − สีแดงสุภาพ = จ่ายมากกว่ารับ, 0 = รับเท่ากับจ่าย; วันโอน/ปรับยอดเท่านั้นแสดงไอคอนโอน และวันไม่มีรายการเว้นว่าง ยอดย่อใช้ K/M/B แตะวันดูยอดเต็มด้านล่าง (วงแหวนคือวันนี้ เครื่องหมายถูกคือวันที่เลือก) สุทธิไม่ใช่เงินคงเหลือหรือเงินใช้ได้หลังกันงบ
วันที่ใช้วันของรายการ: timestamp มีเขตเวลาตีความตามกรุงเทพฯ ส่วนวันที่ล้วน/เวลาไม่มีเขตเวลาคงวันเดิม รวมถึงวันที่นำเข้าจาก Excel
ข้อมูลเดิมยังใช้ `jot-money-v1` ไม่สร้างสำเนารายการ ไม่ต้อง migration ใหม่

ชุดตรวจที่ไม่อ่านข้อมูลการเงินจริง:

```sh
node check.cjs
node category-check.cjs
node new-user-category-check.cjs
node history-check.cjs
node weekly-check.cjs
node history-ui-check.cjs
node capture-ui-check.cjs
node import-check.cjs --synthetic
node import-ui-check.cjs --synthetic
node --check dist/app.js
node --check dist/history.js
```

ห้ามใช้คำสั่ง import-check โดยไม่มี `--synthetic` ในการตรวจอัตโนมัติ เพราะโหมดเดิมอ้างถึงไฟล์ตัวอย่างของผู้ใช้
`history-ui-check.cjs` และ `capture-ui-check.cjs` เป็นชุดตรวจ DOM เสริม ใช้ linkedom ที่ `../.qa/node_modules/linkedom` ในเครื่องพัฒนาเท่านั้น; แอปและชุดตรวจหลักไม่ต้องติดตั้ง dependency นี้
ชุดตรวจ Chrome แยก profile อยู่ที่ `../.qa/history-browser.cjs` และภาพหลักฐานอยู่ใน `../.qa/history-*.png` ไม่ใช้ profile ของผู้ใช้
ผู้ใช้ยืนยันให้อัปเดตทั้งเดโมในเครื่องและเว็บเดโมรุ่น demo.18 วันที่ 7 ตุลาคม 2026; เผยแพร่ผ่าน Git integration ตาม RELEASE_PROCESS.md

## เปิดเดโมบน Windows แบบคลิกเดียว

ดับเบิลคลิก `เปิดเดโม.cmd` ในโฟลเดอร์โปรเจกต์ โปรแกรมจะเปิดเซิร์ฟเวอร์และเปิด `http://127.0.0.1:8000/` ในเบราว์เซอร์ให้เอง

เมื่อต้องการหยุดเซิร์ฟเวอร์ ให้กลับไปที่หน้าต่างสีดำแล้วกด `Ctrl+C`.

ซอร์สโค้ดรุ่นเดโมสำหรับทดลอง วันที่ 5 ตุลาคม 2026 หลังปรับให้ยอดเงินหลังกันงบอยู่บนสุด และมีช่องจดกับปุ่มจดลอย

## เปิดใช้งาน

แตก ZIP แล้วเปิดโฟลเดอร์ `jot-money-demo` ใน Codex หรือโปรแกรมแก้ไขโค้ด
ไม่ต้องติดตั้งแพ็กเกจ npm โปรเจกต์ใช้ HTML, CSS และ JavaScript ธรรมดา

เปิด Terminal ในโฟลเดอร์นี้และรัน (ต้องมี Python):

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

บน Windows ถ้าไม่พบคำสั่ง `python` ให้ใช้ `py` แทน จากนั้นเปิด http://localhost:8000
หยุดเซิร์ฟเวอร์ด้วย Ctrl+C ไม่แนะนำให้เปิด index.html โดยตรง เพราะการเก็บข้อมูลและ API ของเบราว์เซอร์อาจทำงานต่างจากเว็บจริง

## ไฟล์สำคัญ

- `dist/index.html` — โครงหน้าจอ
- `dist/style.css` — สไตล์และขนาดหน้าจอมือถือ
- `dist/app.js` — การบันทึก แก้ไข บัญชี งบ และแผงจด
- `dist/core.js` — การอ่านข้อความ คำนวณยอด และจัดการบัญชี
- `dist/manifest.webmanifest`, `dist/icon.png` — ข้อมูลเว็บแอปและไอคอน
- `check.cjs` — การทดสอบ logic ด้วย Node.js
- `HANDOFF.md` — บริบทและข้อกำหนดสำหรับ Codex ที่รับงานต่อ

ทดสอบด้วย Node.js:

```sh
node check.cjs
node --check dist/app.js
node --check dist/core.js
```

## ข้อมูลเดิม

ตั้งแต่รุ่น 0.1.0-demo.16 เว็บและ ZIP ไม่มีบัญชีหรือรายการตัวอย่าง งบเริ่มต้น 0 ข้อมูลที่จดไว้เดิมยังอยู่ใน localStorage ของเบราว์เซอร์และเว็บไซต์ที่ใช้จด ไม่ล้างอัตโนมัติเมื่ออัปเดต
เว็บ localhost จึงเริ่มแบบว่างเปล่า และไม่ดึงข้อมูลจากเว็บเดิมโดยอัตโนมัติ
เว็บเดิมมีปุ่มส่งออก CSV ในหน้า “รายการทั้งหมด” แต่เดโมยังไม่มีระบบนำเข้า CSV

นี่เป็นเว็บแอป ไม่ใช่ไฟล์ติดตั้ง iOS ยังไม่รองรับใช้งานออฟไลน์ ไม่มีการเชื่อมธนาคารหรือซิงก์ข้อมูลระหว่างเครื่อง
หากต้องการใช้จาก iPhone ต้องมี URL ที่โทรศัพท์เข้าถึงได้; localhost ในคอมเปิดจากโทรศัพท์โดยตรงไม่ได้

ชุดนี้ไม่รวมข้อมูลล็อกอิน Git, ประวัติ Git หรือการผูกกับระบบเผยแพร่เดิม สามารถพัฒนาบนเครื่องได้อิสระ

## นำเข้าจาก Excel

หน้า “รายการทั้งหมด” → “นำเข้า Excel” รองรับ .xlsx ส่งออกจาก Money Manager รูปแบบเดียวกับไฟล์ตัวอย่าง ขนาดไม่เกิน 5 MB และ 20,000 แถว ใช้ THB เท่านั้น ไฟล์อ่านในเบราว์เซอร์โดยไม่ส่งไปภายนอก และไม่ถูกเก็บในชุดเว็บ

เลือกจับคู่บัญชี ประเภท wallet/borrower และหมวดก่อนนำเข้า หมวดที่ไม่มีจะเพิ่มให้ หมวดย่อยและบันทึกเพิ่มเติมเก็บเป็นรายละเอียด คู่โอนสองแถวรวมเป็นรายการเดียว คู่ไม่ครบหรือแถวไม่ถูกต้องจะหยุดและแจ้งแถว ไม่ข้ามเงียบ ๆ

เลือก “แทนข้อมูลเดิม” หรือ “เพิ่มต่อ” และตรวจยอดก่อนยืนยัน บัญชีใหม่เริ่มที่ศูนย์ แทนข้อมูลคงงบที่กันไว้ เพิ่มต่อคงยอดตั้งต้นบัญชีเดิม ป้องกันรายการที่เคยนำเข้าแล้วซ้ำ แต่ไม่เดาว่ารายการที่จดเองซ้ำกับไฟล์ เก็บข้อมูลก่อนนำเข้าครั้งล่าสุดในเบราว์เซอร์เพื่อคืนกลับได้ ปุ่มคืนข้อมูลคืนทั้งบัญชี รายการ และงบเป็นค่าก่อนนำเข้า ไม่ใช่การลบเฉพาะรายการจากไฟล์

บัญชีผู้ยืม: บวกคือเขาติดหนี้เรา ลบคือเราติดหนี้เขา ยอดสองฝั่งแสดงแยกกันและไม่รวมในเงินสด ใช้รายการ adjustment สำหรับการปรับยอดผู้ยืมเก่าจากไฟล์

ทดสอบไฟล์ตัวอย่างที่อยู่หนึ่งโฟลเดอร์เหนือโปรเจกต์ (ไม่เก็บไฟล์ส่วนตัวใน dist หรือ Git): `node import-check.cjs` และ `node import-ui-check.cjs`.
